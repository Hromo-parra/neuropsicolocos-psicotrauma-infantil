## Uso

`python3 -m http.server 8000` desde esta carpeta. Abrir `http://localhost:8000`. Sitio estático sin instalación, servidor de datos, telemetría ni almacenamiento de respuestas. Las fuentes tipográficas externas fueron retiradas; usa fuentes de sistema.

La práctica de reflexión es opcional, basada en el caso ficticio de Mateo. Permite omitir o reiniciar; no contiene soluciones, puntuación ni modelo clínico. Esta edición excluye notas docentes y nueve diapositivas de resolución. Los originales y materiales docentes no forman parte de esta carpeta y no deben subirse al repositorio.

## Publicación

Subir solo el contenido de esta carpeta en una historia Git nueva; no incluir la carpeta de trabajo superior ni el paquete de la candidata anterior. Publicar Pages desde la raíz de la rama principal. GitHub Pages debe configurarse en Settings → Pages → Deploy from a branch → main → /(root). El estado del despliegue debe comprobarse antes de anunciar una URL pública.

La revisión en navegador local cubrió escritorio a 1280px y emulación de ancho móvil a 375px, actividad, salida, reinicio, búsqueda, glosario, casos y navegación de sesiones. No es una prueba en dispositivo físico ni certificación de accesibilidad. El contenido mantiene referencias originales y requiere revisión científica integral antes de atribuir vigencia o exhaustividad clínica.
